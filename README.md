# Chat Prefixes Client

Клиентская часть мода **Chat Prefixes** для V Rising: рисует цветные префиксы в чате
**и в нике над головой**.

## Зачем
Ник игрока — одна строка и для чата, и для таблички над головой. Клиент игры в чате
разметку цвета понимает, а над головой рисует её как обычный текст (видно `<color=#...>`).
Этот мод включает rich-text у текстов, в которых есть теги цвета, — и ник красится везде.

## Как работает
- Сервер (мод `ChatPrefixes`) записывает в ник игрока теги: `<color=#FF0000>ПРЕФИКС <color=#FFD700>Ник</color>`.
- Этот клиентский мод ставит Harmony-патчи на `TMP_Text.set_text` / `SetText` и включает
  `richText` для строк с тегами.

Ничего не отправляет на сервер, не меняет данные игрока.

## Установка (каждому игроку)
1. BepInEx 6 (IL2CPP) для V Rising — как для любых клиентских модов.
2. `ChatPrefixesClient.dll` → `BepInEx/plugins/`.
3. Перезапустить игру.

## Требования
- V Rising 1.1.x (проверялось на 1.1.13).
- Сервер с модом `ChatPrefixes` (он формирует ник с тегами), режим `colored`:
  `.prefix nameplate colored`.

## Сборка
```
dotnet build -c Release
```
Нужен .NET SDK 6. DLL BepInEx/TMP лежат в `libs/`, игровые типы — из NuGet
`VRising.Unhollowed.Client`.

## Ограничения
- Если серверная часть в режиме `clean` (ник без тегов), клиент ничего не рисует.
- Длинные ники упираются в лимит поля имени в игре (61 байт UTF-8).
